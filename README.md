# dezhavu_safe_service_tg_bot

Telegram-бот, выступающий в качестве публичного интерфейса (клиентского компонента) для автоматизированной системы управления подписками. Работает в связке с основным бэкенд-сервисом посредством REST API.

Основной backend-сервис системы подписок и биллинга находится в репозитории: [dezhavu-safe-service](https://github.com/TBargos/dezhavu-safe-service).

## 🚀 Функционал бота

- **Пользовательский интерфейс:** Позволяет клиентам бесшовно управлять своими подписками, просматривать баланс и тарифные планы прямо внутри Telegram.
- **Интеграция с биллингом:** Взаимодействует с бэкендом для генерации платежных ссылок и инициализации транзакций.
- **Управление профилем:** Отображение актуального статуса доступа, дат продления и индивидуальных пользовательских данных.
- **Инфраструктурный контроль:** Поддерживает логику сквозной авторизации и передачи метаданных для автоматического создания учетных записей.

## 🏗 Архитектура и структура проекта

Проект написан на Go и следует общепринятым стандартам организации Go-кода (Standard Go Project Layout), разделяя runtime-инициализацию и изолированную внутреннюю логику.

- **`cmd/app/`** — Точка входа в приложение, инициализация бота, чтение конфигурации и запуск runtime-процессов.
- **`internal/`** — Изолированная бизнес-логика бота, обработчики команд (handlers), middleware и клиенты для работы с внешним HTTP API бэкенда.
- **Язык разработки:** Go (Golang).
- **Специфичный стек:** Telegram Bot API.

## 💻 Развертывание и окружение

Как и вся экосистема сервиса, бот разработан для развертывания в **Linux-среде (Ubuntu)**. Локальное окружение и изоляция зависимостей настроены с использованием виртуализации **VirtualBox**.

### Требования
- Docker
- Docker Compose
- Go 1.22+

### Конфигурация и запуск через Docker Compose

Для удобства локального тестирования и развертывания в проекте подготовлены отдельные конфигурации Docker Compose под различные сценарии запуска.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd dezhavu_safe_service_tg_bot
   ```

2. Сконфигурируйте переменные окружения, создав файл `.env` из шаблона:
   ```bash
   cp .env.template .env
   ```
   *Заполните токен бота и URL адрес развернутого бэкенда (dezhavu-safe-service) в созданном файле.*

3. Запустите контейнеры в фоновом режиме:
   ```bash
   docker-compose up --build -d
   ```
